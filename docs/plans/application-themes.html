Appearance

  • Dark navy-teal surfaces, fine borders, soft cyan selected states, orange primary actions, rounded buttons, and readable sans-serif type.
  • Theme the header, document list, tabs, source editor, preview, banners, and status bar together. Keep the preview's paper/dark toggle available in both themes.
  • Provide an Appearance selector at the foot of the sidebar with Nebula (default) and Legacy choices.

Behavior

Switch instantly without rebuilding the editor, navigating the preview, closing tabs, or changing document state. Save the selected theme in the user's local application settings. Missing or unreadable settings fall back to Nebula; a failed save does not prevent switching.

Verification

Test default selection, persistence, invalid settings, both palette switches, preview colors, unsaved text/selection preservation, and existing document workflows. Inspect screenshots of both themes at the minimum and normal window sizes.

Clarifications

None required. This change styles the editor; it does not add the screenshot's unrelated vault functionality.
