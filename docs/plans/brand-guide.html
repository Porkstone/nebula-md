NEBULA-MD / RELEASE PLAN

One reading desk.
Two considered modes.

Apply the Nebula Applications Brand Guidelines, edition 1.1 to the Windows editor. Preserve its product name, approved icon, editing workflows, and optional Legacy appearance.

Version 1.4.0

Nebula dark

Deep teal structure, low-glare writing surfaces, cyan orientation and focus, and one warm Save action.

Nebula light

White writing surfaces on a cool canvas, deeper teal guidance, and the same orange action with dark text and a stronger outline.

1 · Appearance and behaviour

  • Add Light, Dark and System mode choices, separate from the existing Nebula / Legacy appearance choice.
  • Persist explicit choices; follow Windows application colour changes only in System mode. Preserve the existing dark default and migrate existing settings without losing Legacy preferences.
  • Apply semantic palettes to navigation, source, preview, tabs, menus, notifications, app-owned dialogs and loading backgrounds. Retain the independent preview toggle.

2 · Component refinement

  • Use Segoe UI, sentence-case action labels, existing monospaced source text, 8–10 px corners and consistent spacing.
  • Use visible cyan / teal focus rings, non-colour selection markers and contrast-checked control outlines.
  • Keep dark text on orange buttons in both modes. Preserve keyboard operation, document selection, unsaved edits and preview continuity.

3 · Verification and release

  1. Build and run the Windows smoke suite, extending it for mode persistence, system changes, preview colours, contrast and state preservation.
  2. Inspect captures of light, dark and Legacy at normal and minimum sizes; check keyboard focus and app-owned dialogs.
  3. Bump application and Chocolatey metadata to 1.4.0, publish the Windows executable, and record its size, SHA-256 and exact source commit.
  4. Push the verified changes to master, pack the embedded executable and submit the package to the Chocolatey community repository. Report submission status separately from moderation approval.

Clarifications

None required. The supplied guide specifies the modes, palette and interaction requirements. Windows file pickers and printing remain native system dialogs.
