The selected tab and sidebar entry stay synchronized.

Behavior

  • Allow multiple selections in Open, dropped files, and command-line paths. Reopening a file selects its existing tab.
  • Keep tabs in opening order; sort sidebar entries by filename, ignoring case. Retain the existing source, split, and preview modes.
  • Preserve each document’s text, selection, newline format, unsaved state, and disk-change tracking.
  • Close individual tabs with a close button or Ctrl+W; prompt for unsaved edits when closing documents or the app.
  • Replace the untouched welcome document on the first file open; preserve it if edited. Files from other folders remain supported.

Validation

Build the Windows app and exercise multiple opens, duplicate detection, tab/sidebar synchronization, independent edits and saves, inactive disk changes, closing tabs, and all display modes in an automated WinForms smoke harness. Update the README with the new workflow.

Clarifications

None required. The sidebar lists documents that have been opened, rather than every file in the folder.
